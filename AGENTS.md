# AGENTS.md — Agent Bootstrap

> Mirrors `CLAUDE.md` for agents that don't load it automatically (Codex, Cursor, Copilot CLI, Gemini CLI). Canonical source is `CLAUDE.md` — edit that first, then sync here.

## 1. What this project is

**Keystone** — a shared engineering ecosystem (Golden Path) for 10+ teams. A monorepo with two Git-distributable packages: `devex` CLI (Python/uv) and `@keystone/platform` (TypeScript/pnpm), plus one shared `conventions/conventions.json`.

Invariants: `devex-cli` is self-contained (ADR-0001); DORA metrics derive from the single `DoraEvent` stream (ADR-0002); conventions defined once in `conventions.json`.

## 2. Where it runs

Local (`uv` / `pnpm`) → GitHub Actions (generated by the framework) → AWS (Lambda + API Gateway, `sandbox → staging → production` via CDK).

## 3. Repo layout

`.kiro/{steering,specs}` · `conventions/` · `packages/{devex-cli,platform-framework}` · `docs/{prd,architecture/adr,runbooks}` · `.claude` (rules + skills) · `.github/workflows`.

## 4. Stack

Python 3.12 + uv + Typer/Pydantic (CLI); TypeScript 5 + pnpm + github-actions-workflow-ts + AWS CDK v2 (framework); AWS serverless; GitHub OIDC auth.

## 5. Canonical commands

```bash
cd packages/devex-cli && uv sync --extra dev && uv run pytest
cd packages/platform-framework && pnpm install && pnpm test && pnpm lint
```

## 6. Must-follow conventions

Read the relevant rule in `.claude/rules/` (canonical, single source):
- **PRD-first** (`prd-driven-development.md`) — no feature code without an approved PRD.
- **Work ID** everywhere (branch/commit/PR) — from `conventions.json`.
- **AWS + cost** (`aws-cdk.md`) — serverless, log retention, destroy after demo, no NAT.
- **Security** (`security.md`) — OIDC not static keys; no secrets/PII in logs.
- **Commits/PRs** (`commit-and-pr.md`) — conventional commits, two reviewers, CI green.
- **No push to `main`** (`no-direct-push-to-main.md`).

## 7. Explicit don'ts

- No feature code without a PRD. No cross-package dep on `devex-cli`. No per-language DORA metrics.
- No hard-coded convention patterns (read `conventions.json`). No `.env`/secrets. No `--no-verify`.
- No AWS resource without log retention + `project=keystone` tag. No GCP/Terraform/"Platonica" leftovers.

## 8. Where to find things

PRD → `docs/prd/`; ADRs → `docs/architecture/adr/`; agent context → `.kiro/steering/`; specs → `.kiro/specs/`; AWS → `.claude/rules/aws-cdk.md`.

## 9. When in doubt

Read the code and `conventions.json`. Flag contradictions; fix the doc in the same PR.

## 10. Security baseline (non-negotiable)

Never commit secrets/PII. Never push/force-push to `main`. Never bypass gates (`--no-verify`). Never write feature code
